# Changelog

## 0.1.0 — Initial source build

- Original VEXORA project structure and lightweight UI.
- SVG-based canvas with core shape/path/text creation and selection.
- Document save/open and SVG/PNG export.
- Layers, inspector, undo/redo, grid, zoom and pan.
- Offline rule-based Smart Studio feature set.
- Tauri 2 Linux desktop wrapper source.
- Built-in unit tests for core model and feature helpers.

## 1.0.0 — 2026-10-26
- Added the user's original VEXORA logo asset to the application title bar and favicon.
- Added the user's original Grafio logo and founder details to Help → About VEXORA Studio.
- Updated package and desktop metadata to version 1.0.0.
