# Contributing

- Keep the document model independent of the UI.
- Add unit tests for geometry and document serialization changes.
- Keep core editing offline-first.
- Do not add paid APIs or telemetry as mandatory dependencies.
- Document partial feature coverage honestly.
- Keep low-memory Linux builds in mind; avoid unnecessary packages and unbounded allocations.
- Preserve applicable third-party licences and security notices.
- Do not contribute copied source from other vector editors.
