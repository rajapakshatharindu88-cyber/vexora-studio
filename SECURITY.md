# Security Policy

VEXORA 0.1.0 is an early prototype. Please do not open untrusted SVGs in the application unless you understand the risk of processing untrusted input. The SVG importer parses only selected basic elements, but it has not undergone security certification or fuzz testing.

Do not submit passwords, access tokens, private documents, or confidential artwork in public issue reports. For security-sensitive reports, use the private reporting mechanism of the hosting repository after it has been created.
